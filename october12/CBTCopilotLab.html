Setup

Before you start

Get Copilot ready

  1. Click Open Microsoft Copilot above, or open the Copilot app from the Windows taskbar.
  2. Sign in. Your CBT Microsoft account is best if Copilot Chat is enabled for it; a free personal Microsoft account also works for every exercise.
  3. Start a New chat for each exercise so one scenario does not leak into the next. Prompts marked "Same chat" go into the chat you already have open.
  4. Keep a second tab open with a trusted source: a manufacturer's manual PDF for HVAC, or the NEC through NFPA's free online access for electrical.

Ground rules

  • Never type student names, grades, ID numbers or customer addresses into Copilot.
  • Copilot is a starting point. Every pressure, temperature, code article, ampacity or torque value gets checked before it reaches students.
  • Ask Copilot to question you, not to do the work. These prompts are written that way on purpose.
  • If Copilot says you reached a limit on a special mode such as Think Deeper, switch back to the standard chat.
Prepared by Professor Luis De León for CBT Technology Institute, Flagler Campus. Copilot's answers can be wrong: confirm them in the manual, the code book, a PT chart or with your instructor.
