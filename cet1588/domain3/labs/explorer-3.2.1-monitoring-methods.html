How the network tells on itself.

You can't fix what you can't see. Network monitoring is the set of methods that let a management station learn what every device is doing \u2014 its health, its traffic, its events. But these methods aren't interchangeable: SNMP reports device health, flow data summarizes who's talking to whom, packet capture grabs the raw traffic, and syslog streams event messages. Some pull data on a schedule; others have the device push it the instant something happens. Click through the monitoring stack below to see what each method produces.

SNMP terms the exam loves: poll, trap, MIB, OID

With SNMP, the manager polls (pulls) an agent for values, and the agent can send an unsolicited trap (push) when an event occurs. The data lives in a MIB (Management Information Base) \u2014 a structured catalog \u2014 and each value has a unique address called an OID (Object Identifier). A walk retrieves a whole branch of the MIB. Know all four terms.

Push vs pull — the core distinction
STATION REQUESTS

Pull (polling)

How
The monitoring station asks the device for values on a schedule
Examples
SNMP polling (GET), many API queries
Strength
Regular, predictable snapshots of health metrics
Trade-off
Only as fresh as the polling interval
DEVICE SENDS

Push (event-driven)

How
The device sends data on its own when something happens
Examples
SNMP traps, syslog messages, flow exports, streaming telemetry
Strength
Near-immediate notice of events
Trade-off
You only learn what the device chooses to send

Key terms
SNMP
Simple Network Management Protocol — a manager polls agents for health values and receives traps; data is organized in a MIB and addressed by OIDs.
Trap vs poll
Poll = the manager pulls a value on request/schedule. Trap = the agent pushes an unsolicited alert when an event occurs.
MIB / OID
MIB is the structured catalog of manageable values; an OID is the unique identifier that addresses one specific value within it.
Flow data
NetFlow / sFlow / IPFIX — summaries of conversations (who talked to whom, how much) exported to a collector; great for traffic analysis without full capture.
Packet capture
Recording raw packets (via a SPAN/mirror port or TAP) for deep, packet-by-packet analysis.
Syslog / API / telemetry
Syslog streams event messages (push). APIs and streaming telemetry deliver monitoring data programmatically to modern tooling.
