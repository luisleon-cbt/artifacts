Nothing lasts forever.

Every piece of network gear is on a clock. It ships, it's sold and supported, then the vendor winds it down \u2014 and one day stops patching it entirely. The danger is subtle: an old switch keeps working long after it stops being safe, because once it hits end-of-support every new vulnerability goes unfixed. Knowing where each device sits on its life-cycle \u2014 and what to do at each stage \u2014 is how teams stay secure and avoid nasty surprises. EOL vs EOS — the distinction the exam tests

End-of-Life (EOL) is the announcement that a product is being retired \u2014 it usually stops being sold, but support and patches typically continue for a while. End-of-Support (EOS) is the hard cutoff: no more patches, security updates, or vendor help. A device can run for years after EOS, but every unpatched vulnerability makes it riskier. EOL says "plan ahead"; EOS says "you're now exposed."

Firmware sits below the OS

Think of the stack: firmware is the low-level code embedded in the hardware that makes the device boot and run at the most basic level; the operating system runs on top of it and provides the features you interact with. Both need updating \u2014 but they're different layers, and the exam likes to test that you know which is which.

Key terms
End-of-Life (EOL)
The vendor's announcement that a product is being retired — typically no longer sold or developed, but still supported for a transition window. Your cue to plan replacement.
End-of-Support (EOS)
The hard cutoff after which the vendor provides no patches, security updates, or support. The critical security date.
Patch / bug fix
A targeted update that corrects defects or flaws in software to keep it stable and correct.
Security update
A patch that specifically closes a known vulnerability — the updates that stop once a product hits EOS.
Firmware vs OS
Firmware is low-level code embedded in the hardware; the operating system runs on top of it and delivers the device's features.
Decommissioning
Safely retiring a device: back up/migrate config, wipe sensitive data, update inventory/docs, and dispose responsibly.
