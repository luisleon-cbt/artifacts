One network, three diagrams.

A network you can't see is a network you can't fix. Good documentation is how teams hand off, troubleshoot, and audit \u2014 and the Network+ exam expects you to know that the same network gets drawn differently depending on what you need to understand. A physical (Layer 1) diagram shows cabling and where the boxes sit; a Layer 2 diagram shows switches and VLANs; a Layer 3 diagram shows IP subnets and routing. Network+ Context — Read this first

Objective 3.1 asks you to explain the purpose of these documents \u2014 not to draw them perfectly. The exam tests whether you know which document answers which question: "Where is this device racked?" (rack diagram), "What IPs are in use?" (IPAM), "What uptime are we promised?" (SLA), and especially the difference between a physical/Layer 1 view and the logical Layer 2/3 views of the same network. This explorer is built around exactly those distinctions.

Physical maps to Layer 1; logical maps to Layers 2 and 3

The exam often pairs these terms. A physical diagram is essentially the Layer 1 view \u2014 cabling, media, ports, and where equipment is mounted. A logical diagram captures how data is organized and moves \u2014 the Layer 2 (VLANs/switching) and Layer 3 (IP/routing) views. Same devices; different questions answered.

Key terms
Physical diagram (L1)
Shows actual cabling, media types, ports, and where equipment is mounted. Answers "what plugs into what, and where is it?"
Logical diagram (L2/L3)
Shows how data is organized and flows — VLANs/switching at Layer 2, IP subnets/routing at Layer 3.
Rack diagram
A front/rear view of a rack documenting which device occupies each U position.
IPAM
IP Address Management — tracks subnets, IP allocations, and DHCP scopes so addresses don't conflict or get lost.
SLA
Service Level Agreement — a contract defining expected service levels (e.g., uptime, response time) between provider and customer.
Wireless heat map
A color-coded coverage map from a site survey showing signal strength and dead zones across a space.
